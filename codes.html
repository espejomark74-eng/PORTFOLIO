1. Core Document Anatomy

Every standard HTML document requires this basic boilerplate:

<!DOCTYPE html>             <!-- Informs the browser that this is an HTML5 document -->
<html lang="en">            <!-- Root element with language attribute -->
  <head>                   <!-- Contains non-visible metadata, scripts, and CSS links -->
    <meta charset="UTF-8">  <!-- Character encoding for international support -->
    <title>Page Title</title>
  </head>
  <body>                   <!-- Contains all visible page content -->
  </body>
</html>

6. Key Semantic Elements Summary

  • <header>: Introductory content or navigation bar.
  • <nav>: Container for main navigation links.
  • <main>: The central, non-repeating content of the page.
  • <section>: Thematic grouping of content with a heading.
  • <article>: Self-contained, reusable content (e.g., blog post).
  • <aside>: Indirectly related side-content (e.g., sidebar).
  • <footer>: Page or section footer (copyrights, links).
